# Meta user manual

Use `brainboxemb.meta` when you need to understand the BrainboxEmb repository
collection rather than one implementation repository.

## Find a repository

Start with:

- [repository overview](../repositories/README.md) for maintained public roles;
- [dashboard](../dashboard/README.md) for live GitHub status.

## Find the owner of a change

Use [40 — Design](40-00_design.md) and the relevant domain view.

As a rule:

- product-specific work belongs to the project;
- reusable behavior belongs to its library;
- generic repository mechanics belong to `tool.git-project`;
- domain build/runtime behavior belongs to the domain tool;
- cross-project convention/coordination belongs here.
