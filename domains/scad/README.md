Migration 001 Phases 4 and 5 will decide which information remains current and belongs here.

Do not copy those repositories wholesale. Preserve:

- useful current architecture and ownership boundaries;
- working/project workflow conventions that remain SCAD-specific;
- current-versus-classic/legacy classification;
- active cross-project migration context and important qualification evidence.
